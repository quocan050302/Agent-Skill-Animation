- `app/server/services/tts-service.mjs`: Project-scoped `generateVoicePreview` (<= 150 chars) and `generateNarration` (<= 4000 chars) persisting unique atomic WAV files under `workspace/projects/<projectId>/generated/tts/<hash>-<nonce>.wav`, FFprobe validation, and 48 kHz stereo normalization.

- `app/server/services/media-store.mjs`: `importVoiceover` with strict magic-byte sniffing (`sniffAudioMagic` for WAV/MP3/M4A; rejects ZIP/PNG/JPEG/PDF/HTML), 64 MiB & 180 s caps, single-stream FFprobe validation, non-silent volume check, symlink-safe realpath confinement, 48 kHz stereo WAV normalization, and HTTP `200`/`206` Range streaming.
- `app/server/services/timing-service.mjs`: Wraps `tools/timing/timing_validator.py`, uses FFprobe as duration source of truth, flags duration overflow & speech-rate mismatch, and labels `approximate-silence-dp` honestly as `UNVERIFIED_WORD_SYNC`.
- `app/server/services/subtitle-service.mjs`: Reuses `tools/subtitles/cartoon_subs.py` directly (`punchWords`, `#241726` ink, `#FFE055` highlight, `#FF6347` punch accent, `-c:a copy`), verifies post-burn audio bitstream preservation, supports clean `SUB OFF`, and serves live timed cue lookup for Step 3 preview overlay.
- `app/server/services/qa-service.mjs`: Async parallel evidence-based per-job verifier (`verifyRenderJob`, Q06–Q18 gates) running `probeMp4Async`, 12-tile story contact sheet (`tools/render/contact-sheet.py`), and 4-way bounded parallel subtitle check + batched NumPy lower-third pixel diff concurrently via `Promise.all`.
- `app/server/services/job-manager.mjs`: Async finite-state render orchestrator (`QUEUED -> ... -> COMPLETED|FAILED|CANCELED|BLOCKED|INTERRUPTED`), exclusive use of `ShortRendererSession` with bounded multi-worker parallel rendering (`parallel: true`) overlapped concurrently with audio mastering (`audio_stems.py`/`mix.py`) and `.ass` subtitle preparation via `Promise.all`, non-blocking `muxFramesAndAudioAsync`, double-submit `409` guard, process-tree kill on cancel, startup crash recovery, and SSE event broadcasting.
- `app/server/api-router.mjs` & `app/server/viewer-server.mjs`: Strict loopback `127.0.0.1` binding + Host/Origin validation, raw URL traversal & dotfile rejection, all Studio REST & SSE endpoints, compiled React SPA at `/`, and untouched legacy viewer preserved at `/legacy`.
